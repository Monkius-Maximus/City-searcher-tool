World City Map · navegador de localidades

A árvore de contenção do projeto, do país ao edifício. Clique para selecionar, clique de novo para entrar. Nenhuma arte existe ainda — cada nó mostra um placeholder determinístico e os slots que ele espera.

Os quatro estados de uma localidade

O que torna uma árvore desse tamanho viável não é a estrutura de dados — é que só um caminho fica vivo por vez. Um nó só pode estar simulado se o pai estiver ativo. Todo o resto é registro.

bytesRegistro

Nome, tier, arquétipo, contagem de filhos. Todas as ~5.570 cidades, sempre.

kilobytesVitrine

+ thumbnail, pins dos filhos, dados de painel. O contêiner que você está olhando.

megabytesAtivo

+ placa em alta resolução, máscaras, áudio. Um por vez — a cidade em que você entrou.

orçamento inteiroSimulado

+ agentes e interações rodando. Um por vez — o local onde o jogador está.
